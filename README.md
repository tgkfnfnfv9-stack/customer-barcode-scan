# お客様用 バーコードスキャン｜株式会社小林機械

機械の銘板バーコードを iPhone で読み取り、写真・機械情報・公開価格・仕様を画面内に表示するお客様向けツールです。
ログインは不要。読み取りエンジンは端末内で動き、機械情報の取得にはネット接続が必要です。単一の `index.html` だけで動きます。

**公開URL：** https://tgkfnfnfv9-stack.github.io/customer-barcode-scan/

---

## 使い方

1. 上記URLを iPhone の Safari で開く（ホーム画面に追加すると便利）
2. 画面下の「スキャン」を押し、カメラの使用を許可する
3. バーコード全体を枠に合わせると自動で読み取る。読み取り成功でカメラが閉じ、履歴へ登録して一覧に戻る（最新が一番上）
4. 次の機械を読むときは、もう一度「スキャン」を押す
5. 読み取り履歴に写真・機械名・メーカー・型式・年式・公開価格が表示される。仕様は「仕様を見る」で開く

撮影ボタンの操作は不要です。読み取れない場合は、カメラを開いたまま再試行します。
カメラを閉じるか画面を離れると停止します。「アルバムから選ぶ」と番号の直接入力も使用できます。
連続スキャンにはHTTPSと対応ブラウザが必要です。

### 主な機能

- 読み取り履歴が積み上がる（同じコードは重複せず先頭へ移動）
- 各コードから公開情報を取得して表示（公開価格が設定されていない機械は金額を灰色の `---` で表示）
- 取得に失敗したときは「再取得」で再試行できる（通信・本文の受信は15秒でタイムアウト）
- 「仕様を見る」の開閉や別の機械情報の取得で、閲覧中のカードの位置を保つ
- 写真を取得できないときは「写真なし」を表示
- カメラが使えないときは番号を直接入力して登録することも可能
- 個別コピー（各行）／すべてコピー（まとめて）／個別削除（✕）／すべてリセット
- 履歴は端末内に保存（閉じても更新しても残る）
- 写真解析中のリセットや画面離脱は解析を中止し、古い結果で履歴を復活させない

## 更新方法

`index.html` を新しい版で上書きコミットするだけで、数分後に公開URLへ自動反映されます（URLは変わりません）。

1. リポジトリの `index.html` を開く
2. 鉛筆（Edit）または「Upload files」で新しい版に差し替え
3. 「Commit changes（変更をコミット）」で保存

## 技術メモ

- 単一 HTML（CDN・ネット依存なし）。読み取りエンジンは ZXing-C++（WASM）を base64 で埋め込み
- 取得先：`https://www.kkmt.co.jp/staff/api/stocks/<コード>`（認証情報は送らない）
- 表示する金額はログインなしで返る `public_price` のみ。`price` や `current_price` などの社員価格・メモは使用しない
- 履歴に保存するのは番号と読み取り形式のみ。情報は起動時に再取得する
- 印字と符号化値が異なる機械は、`index.html` 内の `OVERRIDE_MAP` に登録して対応


### 開発時の確認

Node.js 18以降で `node --test tests/live-scan.test.cjs` を実行する。カメラの終了後の結果、履歴の検証、手入力、仕様開閉、通信とJSON本文のタイムアウト、古い応答の無視、コピーと写真解析の中止を確認する。

GitHub Actions は Chromium/WebKit でも仕様開閉と閲覧位置、社員情報・認証情報を使用しない公開表示、金額なし `---`、写真失敗、読み取りエンジン初期化失敗をテストデータで確認する。実API・実認証へ接続しない。ローカルでは `npm install --no-save --package-lock=false playwright@1.62.1`、`npx playwright install --with-deps chromium webkit`、`node --test tests/browser-layout.test.cjs` を実行する。

端末固有のカメラのピント・速度は実機で確認する。
